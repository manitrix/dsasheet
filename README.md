# DSA Garden

Open **index.html** in your browser. No Go installation or code runner is needed. An optional static preview is available with `node server.cjs` at http://127.0.0.1:4173.

## Paste and practice

1. Open a question and paste your LeetCode solution under **Paste / edit code**. Any language works. It saves automatically.
2. Click **Practice**. Your pasted code stays visible in gray in the same editor. Type directly over it: matching characters turn green and mismatches turn red.
3. Use **Blank on** to hide untyped characters, **Hide guide** for recall practice, or **Restart practice** to try again. Accuracy, progress, and a timer update as you type.
4. Switch back to **Paste / edit code** to change the reference. Your code and typing draft are saved separately per question.

Nothing compiles or executes. Feedback compares your typing with the pasted reference.

The roadmap also supports editable questions/topics, favorites, mastery, notes, revision reminders (1, then 7, then 30 days), an activity calendar, date filters, and .ics calendar reminder downloads. Backups include your full workspace. Keep the same browser and address, and export a backup before clearing storage or changing devices. Older mastery and favorite flags migrate without inventing solve dates.

Run checks with `node --test tests/*.test.cjs`.
